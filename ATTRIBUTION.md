# Origine et usage local

ElpoAiAutoCapcut (depuis 0.2.0, ici 0.5.0) est une adaptation locale préparée pour le propriétaire du fichier TryAIToday.AutoCapCut-0.1.2-arm64.dmg fourni dans cette conversation.

L'installateur réutilise le runtime Electron, les frameworks et les notices contenus dans ce DMG. Les modèles de matériaux CapCut et les fonctions de clonage dans lib/template.js dérivent du code TryAIToday AutoCapCut 0.1.2, auteur TryAIToday. L'interface, le moteur de rendu ELPO, le pilotage de CapCut, le planificateur contrôlé, le moteur de validation, les sauvegardes transactionnelles, le worker, l'installateur et les tests de cette adaptation ont été développés pour cette demande.

Cette adaptation est préparée pour l'utilisation locale du demandeur. Les éléments tiers conservent leurs attributions ; ce paquet ne prétend pas être une version officielle TryAIToday ou CapCut.

Aucun code ViralDNA n'est intégré. Les deux démonstrations ont servi à comprendre des workflows et formats de nommage.
